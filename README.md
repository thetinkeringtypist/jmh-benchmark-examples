JMH Examples
============
This repository contains some examples of how to use JMH to measure the runtime performance
of methods and code written in Java. JMH benchmarks are setup very much like JUnit tests.
They can be tracked in a repository to check performance changes over time.

This project uses following:

* IntelliJ
* Maven
* Java 21
* JMH
* The JMH plugin for IntelliJ

Most of the benchmarks measure differences between arrays and lists to easily demonstrate the
performance differences between them. However, this does not mean that one implementation should
be favored over another. Each one has its own place in code and provides value in unique ways.

Enjoy!
